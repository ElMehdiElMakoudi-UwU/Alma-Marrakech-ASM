# Alma Marrakech

One-page presentation site for the Alma Marrakech residence. All facts and images come from the September 2026 dossier.

## Run and build

```bash
npm install
```

```bash
npm run dev
```

```bash
npm run build
```

The build goes to `dist/`. It is a static site, so it can be uploaded to any host (Netlify, Vercel, Cloudflare Pages, OVH and so on). It needs a web server and won't run by double-clicking `index.html`.

## Where things are

| To change | Edit |
|---|---|
| Text, figures, contact details | `index.html` |
| Colours, fonts, spacing | Top of `src/style.css` |
| Scroll animations | `src/main.js` |
| Palm shadows | `src/palm.js` |
| Menu, plan hotspots, tabs, slider | `src/ui.js` |
| Images | `public/img`, generated by `tools/extract_assets.py` |

Plan hotspots are placed by percentage in `index.html` (`style="left:…;top:…"`).

## Regenerating images from a new PDF

```bash
pip install pymupdf numpy opencv-python-headless pillow
```

```bash
python tools/extract_assets.py "path/to/dossier.pdf"
```

The image numbers in the script belong to the September 2026 PDF. A new export will change them, so update them first.

## Deploy on Coolify

The repository has a `Dockerfile`: it builds the site and serves it with nginx on port 80.

1. Put this folder in a Git repository, with `Dockerfile` at the root, and push it to GitHub, GitLab or similar.
2. In Coolify: **New Resource**, then **Public Repository** or **Private Repository**, and pick the repository and branch.
3. Set **Build Pack** to **Dockerfile**. Leave the base directory as `/`.
4. Set **Ports Exposes** to `80`.
5. Set **Domains** to the final address, for example `https://alma-marrakech.ma`. Point the domain's DNS at the server first, so the HTTPS certificate can be issued.
6. Under **Environment Variables**, add `SITE_URL` with the same address, and make it available at build time. It's used for link previews and the canonical link. The site runs without it, but previews on WhatsApp and social networks won't show the image.
7. Deploy. If you change `SITE_URL` later, redeploy, because it's read during the build.

The health check is built into the image (`/healthz`), so Coolify needs no extra health check settings.

To test the container locally:

```bash
docker build --build-arg SITE_URL=http://localhost:8080 -t alma-marrakech .
```

```bash
docker run --rm -p 8080:80 alma-marrakech
```

## Before going live

- Confirm the open points: exact location (the PDF footer says Assilah), total lot area (31,650 or 31,765 m²) and the missing Type 02 upper floor plan.
- Add a way to get in touch: the closing section currently has no contact details.
- Check the licence for the satellite base maps (`carte-*.webp`) and add any required credit.
